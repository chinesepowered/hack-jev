The problem

Coding agents on auto-approve are one poisoned README away from disaster.

curl … | sh

Runs a stranger's script because an issue told it to.

cat ~/.ssh/id_rsa

Reads your keys while "adding a setup section to the README".

git push --force

Rewrites main while it was supposed to fix one test.

Approving hundreds of calls by hand is exhausting, so people turn approvals off. An LLM judging every call costs seconds and cents per call, hundreds of times a session, so nobody runs one.
