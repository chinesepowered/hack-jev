# Flinch demo app

A tiny project with a failing test, used to demo Flinch live. `.claude/settings.json` wires Claude Code's hooks to the Flinch server.

1. In the repo root: `pnpm start` (dashboard at http://127.0.0.1:7777).
2. In this folder: `claude`, then ask it to "fix the failing test".
3. Watch every tool call appear on the dashboard with its verdict.
